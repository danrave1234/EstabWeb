# Pivot Plan: Managed Website Launch Platform for Local Businesses

## Why this pivot fits EstabWeb now

EstabWeb should not try to beat `Wix` or `GoDaddy` as a broad DIY website builder. They are stronger on template volume, self-serve editing maturity, ecosystem breadth, and mass-market pricing familiarity.

The product documented in `AGENTS.md`, `README.md`, and `docs/FEATURES.md` already points to a different and more defensible offer:

- admin-created template drafts in `/admin/template`
- redemption-code onboarding instead of blank-canvas setup
- client editing through `draft_config` and approval/publish workflow
- AI-assisted section editing and AI SEO tools
- analytics focused on leads and business questions
- subdomain launch with upgrade path to custom domains
- repeatable industry presets, with especially deep support for gyms

That means the real pivot is not “be another website builder.” It is:

> **Be the managed website launch platform for local businesses that want a professional site live fast, then use AI-assisted tools to keep it updated.**

## Current product reality

### What EstabWeb already supports well

- **Managed launch flow**
  - Admin prepares a business-specific draft in `/admin/template`
  - Admin generates a redemption code when the prospect is ready
  - Client redeems the code in onboarding and receives a prebuilt starter site
- **Client editing without full DIY complexity**
  - Dashboard edits save to `draft_config`
  - Free plans use change requests for publish
  - Active paid plans can publish approved updates into `current_config`
- **AI-assisted operations already in the product**
  - AI template population for admin draft creation
  - AI section editing in the dashboard
  - AI SEO generation for titles, descriptions, and keywords
- **Business-focused platform features**
  - multi-tenant public site delivery
  - analytics and lead tracking
  - custom domain mapping
  - subscription tiers and plan gating
- **Repeatable vertical structure**
  - presets and section workflows already exist
  - gym-specific schema, config keys, and section variants are notably more mature than other verticals

### What EstabWeb is not today

- not a blank-canvas design tool
- not a broad app-marketplace platform
- not a feature-parity alternative to `Wix`
- not a generalized ecommerce platform across all business types
- not yet a proven multi-vertical system with equal readiness for every niche

## Recommended positioning

### Core positioning

**Managed website launch platform with AI-assisted post-launch editing for Philippine local businesses.**

This keeps the offer aligned with the real workflow:

1. Admin creates a draft
2. Prospect redeems a code
3. Client edits in the dashboard
4. Client publishes directly or submits a change request
5. Public tenant site runs on subdomain or custom domain

### Messaging shift

Move away from:

- “build your own website”
- “AI website builder”
- “templates for everyone”

Move toward:

- “we launch your website for you using a proven template workflow”
- “made for local businesses that need inquiries, not design complexity”
- “AI helps you improve content after launch instead of replacing the whole service”
- “start on a hosted tenant site, then upgrade to your own domain and higher plan”

### Competitive angle

Against `Wix` and `GoDaddy`, EstabWeb should compete on:

- faster guided launch for non-technical businesses
- stronger admin-operated setup flow
- repeatable niche presets instead of generic choice overload
- localized AI-assisted content and SEO workflow
- business-facing analytics tied to leads and section performance
- service + software hybrid delivery rather than pure self-serve tooling

## Current reality vs required work

### Can be sold now using the current product

- managed draft creation by admin
- redemption-code onboarding
- dashboard editing with `draft_config` / `current_config` lifecycle
- free-plan change-request flow and paid-plan publish flow
- AI-assisted section editing
- AI SEO support

### Should be framed as follow-on product work

- stronger niche packs beyond the currently mature presets
- deeper operational playbooks for clinics, salons/spas, and home services
- broader multi-page vertical storytelling as a standard cross-niche offer

This distinction is important: the pivot plan should sell what is already real and treat broader vertical expansion as the next layer, not as current capability.

## Best-fit initial niche based on shipped assets

### Primary operational wedge: gyms and fitness studios

Gyms should be the first official niche wedge because the existing product already has the deepest operational support here.

Evidence from current docs and config conventions:

- dedicated gym config keys already exist
- dedicated `gym--*` section IDs already exist
- presets already account for gym-specific sections
- the workflow is a strong fit for class schedules, memberships, trainers, programs, results, facilities, and FAQs
- this makes the admin draft workflow more repeatable today than for less-supported niches

### Why gyms are the strongest current fit

- repeatable site structure
- strong visual before/after and trust content opportunities
- clear inquiry goals such as trial passes, membership interest, class signups, and calls
- easy alignment with AI-assisted copy and SEO generation
- strong fit for analytics that answer business questions like which section drives trial inquiries

### Recommended gym offer shape

Standard gym launch package should emphasize pages/sections such as:

- hero with offer and trust cues
- programs or class types
- trainer profiles
- schedule and membership options
- results or testimonials
- facility highlights
- FAQ
- contact or trial CTA

## Secondary expansion candidates

These can be strategic next niches, but they need more productized depth before they should become the lead story:

### Clinics

Strong commercial potential, but the current docs do not show the same degree of dedicated schema/preset maturity as gyms.

### Salons and spas

Likely a good fit for templated trust/booking sites, but should follow after stronger preset and content workflow support is built.

### Home services

A practical category for lead capture and local SEO, but needs more niche-specific preset structure and operational packaging.

## Near-term execution priorities

### 1. Tighten go-to-market positioning around the actual workflow

- Reword homepage, sales decks, and admin-facing pitch material around managed launch plus AI-assisted updates
- Stop describing EstabWeb as a general-purpose website builder
- Show the actual journey: admin draft -> redemption code -> dashboard editing -> publish/change request -> live tenant site

### 2. Make gyms the lead vertical in product marketing

- Use existing gym presets and schema depth as the proof point
- Build first-call sales messaging around gym/fitness studio outcomes: trial leads, membership interest, coach trust, class visibility
- Package the launch offer around the sections the current system already supports well

### 3. Turn `/admin/template` into the operational centerpiece of the service

- Treat admin draft creation as the start of fulfillment, not a side tool
- Standardize draft inputs for niche-specific assets, copy, and offer framing
- Use AI template population to speed up niche-specific first drafts rather than promise generic instant site creation for everyone

### 4. Align onboarding and plan messaging with the real product

- Make redemption codes central to the sales and onboarding narrative
- Position `Starter` (`basic`) as the guided launch tier, not a stripped DIY tier
- Position `Business` (`pro`) and above around custom domains, stronger analytics, and richer ongoing control

### 5. Use analytics as a conversion differentiator

- Surface business-language reporting in sales messaging
- Emphasize that the platform helps answer which sections, pages, and traffic sources create inquiries
- Keep analytics tied to business outcomes, not vanity metrics

## Follow-on expansion path

### Phase 1: win one repeatable niche

- make gyms the lead operating model
- refine the gym launch package, draft prompts, and sales narrative
- collect proof that the workflow consistently launches faster than agency-style one-off builds

### Phase 2: formalize the service wrapper

- define turnaround, revision, approval, and publish expectations
- standardize what admin builds before redemption and what the client edits afterward
- clarify where AI is used in fulfillment versus client self-service

### Phase 3: expand to the next verticals deliberately

- add stronger presets, section mappings, and onboarding guidance for clinics, salons/spas, or home services
- avoid announcing a niche as “supported” until preset depth and workflow quality are genuinely ready

### Phase 4: expand breadth only after the core wedge is proven

- widen vertical support gradually
- improve multi-page and richer niche storytelling where it aligns with paid-plan value
- keep the platform opinionated instead of drifting toward general builder parity

## Final recommendation

EstabWeb should pivot to:

**A managed, template-driven website launch platform with AI-assisted post-launch editing for Philippine local businesses, starting with gyms as the most operationally supported niche and expanding to other service categories only after that workflow is repeatable.**
